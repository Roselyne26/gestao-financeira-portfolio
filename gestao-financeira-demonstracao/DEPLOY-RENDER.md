# Gestão Financeira — Demonstração

Todos os dados são fictícios. Execute `npm ci` e `npm start` na pasta backend.
Abra http://localhost:3000. Acessos públicos de demonstração: master / demo123 e operador / demo123.

O banco é criado exclusivamente em backend/data/demonstracao.sqlite. Caminhos externos de banco são ignorados. Para recriar os exemplos, pare o servidor e remova somente esse banco.

Compartilhe apenas frontend, backend/src, backend/package.json, backend/package-lock.json e este documento. Não inclua bancos alterados durante uso, node_modules, .env, backups, credenciais ou histórico Git.
